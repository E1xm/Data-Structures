## 单题笔记模板

- **题目**：用自己的话转述题意（不照抄原文），标注出处页码/题号
- **设计思想**：一句话核心思路
- **代码**：关键行有注释
- **复杂度**：时间 + 空间，附推导
- **踩坑记录**：编译错误、逻辑 bug、边界情况——复习时最有价值的部分
